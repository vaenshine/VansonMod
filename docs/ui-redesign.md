## 页面及功能基线

详细清单按实现范围记录：

- [内存、字符串、Hex、特征码与调试](ui-inventory-memory.md)

设置页完整保留搜索起止地址、联合范围与顺序/锚点模式、结果上限、浮点容差、锁定频率、模糊重复次数、主题、语言、防休眠、应用图标、更新、社群/项目链接、声明、重置及可选文件清理。设置项使用紧凑同行布局；长控件及辅助功能大字号时自动改为纵向排列，保持内容可读。数值使用严格解析，失败保留上一个有效值。默认值与重置行为统一；语言切换沿用现有导航生命周期修复。

## 设计规范

- 原生 UIKit 导航与表单。主导航保留五个入口；二级页面保留上下文与返回路径。
- 浅色使用冷灰分组背景和白色内容层，深色使用系统语义背景；靛蓝强调主操作，红色表示破坏性操作，绿色表示已完成/运行状态。
- 内容边距 16pt，卡片圆角 16pt，连续圆角，间距 8/12/16/24pt。技术地址、字节和值使用等宽字体。
- 常用按钮和输入区域以 44pt 为基准。状态同时通过文本或符号表达。图标操作具有辅助功能名称。
- 复杂表单标签放在控件上方，设置项采用紧凑同行布局；操作分为主操作、次级动作和批量动作。工具选项可滚动，避免压缩全部文本。
- 表头按实际宽度计算；横竖屏与键盘通过约束/可滚动区域适配；空列表提供页面目的与下一步提示。
- 共享组件集中在 `VMUIHelper`，已有业务模型和文件格式保持兼容。

- 指令库搜索栏固定在顶部，内存浏览数值列随横屏和选择状态调整。RVA 批量操作改为可容纳小屏的按钮组。
- 模拟器测试增加键盘输入、滚动边距恢复、Hex 草稿和脚本清空撤销；测试程序支持 `--interactive` 持续交互模式。
