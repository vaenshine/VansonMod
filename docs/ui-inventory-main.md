# 主界面功能清单与重构约束

本清单依据 2026-10-03 工作区源码记录，先于主界面重构编写。现有功能、导入格式、进程上下文、只读规则及中英文以外语言均属于保留范围。

## 全局导航

`src/core/VMRootViewController.mm` 提供应用、修改、补丁、工具箱、设置五个独立导航栈；支持长按标签排序、恢复默认、更新角标、声明展示、跨页通知和语言刷新。标签身份由 tag 表达。重构保留标签身份、选中页与导航行为。

## 应用

`src/ui/main/VMAppSelectViewController.mm`：运行中、全部安装、系统进程三种筛选；按应用名、Bundle ID、PID 搜索；下拉刷新；收藏优先排序；显示图标、版本和进程信息。应用操作包括附加、启动、复制 PID、复制 Bundle ID、收藏、添加指针、创建数据备份、进程审计及终止进程。导航提供全局备份管理。添加指针支持解析文本链、说明和数据类型。备份异步执行并反馈成功或失败。

依赖 `VMMemoryEngine`、`VMBackupManager`、`VMPointerManager`、`VMLockManager`、LSApplicationWorkspace、sysctl，以及备份列表与审计控制器。

## 修改与搜索结果

`src/ui/main/VMModifierViewController.mm`：精确、模糊、联合搜索；I8/I16/I32/I64/U8/U16/U32/U64/F32/F64/字符串；首次搜索与继续搜索；各搜索模式输入历史。模糊筛选支持增加、减少、保持、变化及指定增减量，可配置重复筛选次数。联合搜索含帮助与锚点/顺序行为。支持附近搜索、范围确认、小于/大于/区间过滤、刷新实时值和重置。

结果显示地址、实时值、访问状态、置顶状态；点击调用通用内存动作，滑动支持删除、置顶、锁定和收藏。批量模式支持全选、范围选择、复制地址、修改、锁定、收藏和删除。搜索时间线支持恢复结果、选择恢复值、清空时间线和撤销上次写入。导航支持直接跳转内存浏览器或 Hex 编辑器。指针搜索支持多层上下文与返回恢复。显示总结果数及显示上限。

依赖 `VMMemoryEngine`、`VMLockEngine`、`VMMemoryActionSheet`、内存浏览器、Hex 编辑器与指针搜索工具。重构保留引擎接口和全部搜索模式。

## 工具箱

`src/ui/main/VMLockListViewController.mm` 提供七个分类，支持分类切换、下拉刷新、长按进入批量、自动定位当前应用、应用文件夹导航、导入、分享和拖放排序。

| 分类 | 功能 |
| --- | --- |
| 地址锁定 | 手动添加、实时值、锁定开关、内存动作菜单、备注、批量复制/修改/导出/删除、快照保存/恢复、撤销上次写入 |
| 收藏 | 手动添加、实时值、内存动作菜单、备注、批量复制/修改/导出/删除、快照保存/恢复、撤销上次写入 |
| 指针 | 按应用管理、导入、解析与实时值、写值与锁定、滑块/开关、编辑元信息与类型/范围、复制链、复制偏移副本、内存/Hex 跳转、重命名/导出/删除 |
| RVA | 导入、模块及偏移、原始/替换字节、应用开关、写入完整性检查、编辑元信息、重命名/导出/删除 |
| 特征码 | 导入、扫描/校验、结果列表、修改结果、结果配置、滑块/开关、编辑元信息、重命名/导出/删除 |
| 校验 | 导入校验文件、按应用管理、重命名/导出/删除、进入指针校验页 |
| 脚本 | 新建/导入、运行状态及日志、元信息编辑、编辑器、重命名/导出/删除 |

依赖 `VMLockManager`、`VMLockEngine`、`VMPointerManager`、`VMImportHandler`、`VMDataSession`、`VMScriptManager` 以及专用卡片和编辑控制器。工具箱保存的文件及格式属于保留范围。

## 脚本编辑与文档

`VMScriptViewController.mm` 支持内容编辑、作者和说明、名称/描述编辑、撤销、清空确认、运行与控制台、保存。导入脚本遵循只读规则。快捷命令及模板将代码插入选区。`VMScriptToolsViewController.mm` 提供 26 个 API 命令入口及 HTML 完整指南，指南支持复制和插入代码。

重构提升编辑空间、字体、键盘避让、保存状态、只读状态和工具可达性；保留模板内容、脚本 API 和已有持久化逻辑。

## 设置与备份

`VMSettingsViewController.mm` 提供搜索起止地址、联合范围/模式、结果数、容差、锁定间隔、主题、模糊重复、语言、防休眠、社群链接、图标选择、更新、声明和恢复默认。可选清理工具文件，保留用户备份。设置和根导航由独立重构工作负责。

`VMGlobalBackupViewController.mm` 为旧全局目录页，显示备份目录与数量、进入应用备份列表及删除目录。目前应用页直接进入 `VMBackupListViewController`。旧页继续维护布局、空态和删除反馈。

## 已确认的修复目标

1. 应用附加成功按稳定标签身份跳转修改页，兼容标签排序。
2. 搜索结果置顶时保留原始数据类型。
3. 脚本键盘处理调整有效约束；现有未赋值 `bottomBar` 的变换没有布局效果。
4. 清理重复的进程切换通知注册。
5. 指针数据类型选择使用完整枚举；I8 的零枚举值保持有效。
6. 脚本指南采用弱引用消息代理并释放 handler。
7. 增强窄屏、旋转、长翻译、Dynamic Type 和 VoiceOver。

## 设计规则与检查

采用原生 UIKit、系统分组画布、16 点外边距、16 点连续圆角卡片、靛蓝主操作、语义化红色删除动作。技术数据采用等宽字体；主要触控目标至少 44 点；次要操作逻辑分组；空态提供页面上下文。界面文字继续从 `TR` 取得。

检查覆盖编译、共享组件调用、通知注册、标签路由、枚举映射、键盘布局、导入只读保护、所有原有操作入口和本地变更隔离。设备上的进程附加、内存扫描、写入、备份恢复等功能需要目标 iOS 环境验证。

## 已实施的主界面调整

应用采用独立标题、筛选与搜索区、可换行的应用身份列表；修改页采用可横向浏览的完整数据类型和操作区，保留所有搜索入口，结果按地址与值分行。工具箱采用完整尺寸的数值卡片、显式批量选择入口、底部操作栏及已选数量；批量删除展示分类与数量确认。地址锁定和收藏的批量导出接入现有文本导出器；文件夹模式只展示可用操作。

脚本编辑器增加有效键盘避让、完成按钮、未保存状态、可读等宽字体；导入脚本的代码插入与撤销遵循只读规则。快捷命令支持按名称或代码搜索；模板页面使用弱引用消息代理。旧备份目录页增加统一空态及删除失败反馈。进程枚举校验 sysctl 返回值和分配结果。

设备端编译使用当前本机 iPhoneOS 27 SDK；命令局部的 `ADDITIONAL_CFLAGS='-Wno-error=#warnings'` 将 SDK 对 iOS 14 目标的 libc++ 警告保留为警告，项目最低版本继续保持 iOS 14。完整编译已通过一次，后续调整通过增量编译和模拟器页面检查验证。

模拟器已检查应用、修改、工具箱、脚本编辑器及快捷命令的 320 点窄屏和深色截图。检查后修复应用搜索栏重新挂载、默认应用图标着色、窄屏命令两列排列，并在修改页空态增加返回进程选择的直接入口。最终截图由统一 UI 检查脚本生成。
