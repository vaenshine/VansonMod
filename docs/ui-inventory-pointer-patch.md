## 重构验收重点

1. 指针搜索 header 的内容卡、统计条、底部形成完整约束链；旋转和长译文保持正确尺寸。
2. 验证器标题与筛选控件分区；统一按钮高度；大字号和窄屏适配。
3. 编辑页使用独立草稿：取消保留原模型；未滚动到的字段保存时保留原值；可见行数与内容一致；脚本编辑入口有明确标题。
4. 跳转按 controller 身份选择，保留自定义底部标签顺序。
5. 指针会话批量删除后同步编辑状态、模型和列表；导入、重命名与单项删除流程保留。
6. 单应用备份始终使用明确传入的应用标识；空态随文件夹切换刷新。
7. 卡片、输入和按钮使用统一颜色、间距、圆角；关键控件触控高度 44pt；技术数据使用等宽字体；图标操作、滑块和开关提供可访问名称。

## 验证入口

- `tests/run_string_memory_tests.sh`：字符串内存编辑逻辑。
- `tests/run_language_ui_tests.sh SIMULATOR_UDID`：真实根导航/设置/语言切换，其他页面使用替身。
- Theos 全量本地编译与设备包检查。
- UIKit 模拟器真实页面布局检查：窄屏、横屏、深浅色、大字号、取消编辑、离屏字段保存、标签排序后转场。
- 目标进程操作及越狱设备能力需要真机验证。

## 本轮实现与回归关注

- 搜索参数在常规宽度使用三列；窄屏和辅助功能字号使用纵向布局。搜索/验证的 header 通过完整约束链计算高度，统计区域独立显示。
- 通用编辑器以完整预建字段保存草稿，模式选择直到保存时才写入模型。类型选择包含 11 种引擎类型，索引对应 `VMDataType`，保留无符号整数与字符串。
- 编辑器字段标签与控件纵向排列；脚本代码入口单列呈现；可复制信息通过行描述确定操作。导入项目继续保护作者、特征码、偏移与补丁原始/目标字节。
- 指针搜索后的验证跳转、验证器的应用选择跳转按控制器身份定位，支持自定义标签顺序。
- 指针会话的根列表支持从文件元数据识别应用并导入；存在的单应用列表继续保留当前应用范围。批量删除完成后重新加载磁盘状态并退出选择，文件错误保留提示。
- 备份显式 `bid` 优先，离线查看与连接其他进程时保持目标应用。空态随目录导航重新计算。
- 补丁创建提供管理入口，使用共享字段和主次按钮样式；偏移需要完整十六进制输入。原始字节缓存绑定地址和字节长度，并随进程/模块切换清理。
- 三种卡片统一 16pt 内边距与连续圆角、可换行技术信息、44pt 关键操作；特征码结果的数值、显示模式及滑块/开关分行布局。
- 真实 UIKit 截图检查发现并修复空态重复、模块提示重复、系统 Edit 与应用语言不一致；共享按钮填充问题交由 `VMUIHelper` 修复。

编辑器稳定回归入口：`fields`、`modeSegment`、`typeSegment`、`draftMode`、`rows`；保存 `onSaveBtn`、取消 `onCancel`、切换模式 `onModeChange:`。重点断言：取消后模式保留、未滚动保存保留作者和其他模式参数、UInt64/String 类型保留、导入字段保护。
