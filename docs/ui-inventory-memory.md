# 内存与调试页面功能清单

本清单记录 UIKit 重构前的功能、交互和需要保留的数据完整性规则。范围为 `src/ui/memory`；调试页面也位于这个目录。

## 内存浏览器 · VMMemoryBrowserViewController

- 显示 I8、I16、I32、I64、F32、F64、字符串；显示地址、相对基址十六进制/十进制偏移、当前值。
- 基址定位和高亮；前后分页加载；数值缓冲区最多 1000 行；可见行自动刷新，滚动时暂停刷新。
- 手动刷新、绝对地址跳转、正负偏移跳转、撤销上次手动写入。
- 点击地址打开统一动作面板；长按进入多选；全选已加载地址；批量固定值写入、递增写入、收藏、锁定、复制排序地址。
- 字符串模式扫描邻近内存并呈现字符串、地址和原始字节长度，点击进入统一动作面板。
- 重构关注：类型栏在内容区域布局；多选有显式入口和勾选状态；请求绑定类型、地址和进程；严格解析地址与偏移；前后分页保留可见位置。

## 十六进制浏览器 · VMHexEditorViewController

- Hex、Hex/ASCII 分栏、ASCII 三种模式；分栏同步滚动与选中行。
- 前后读取内存、地址跳转、显示起始地址；点击行打开字节编辑器。
- 可执行内存写入提醒；成功写入后更新本地缓冲区；写入失败提示。
- 重构关注：窄屏可读字节行、足够点击高度、响应式列宽、部分尾行、安全跳转、保存结果反馈。

## 字节行编辑器 · VMHexRowEditorViewController

- 显示编辑地址和原始字节；编辑 Hex；实时 ASCII 预览。
- 保存前校验字节数量；向浏览器返回编辑结果；键盘避让和收起。
- 重构关注：实时格式与长度状态、明确非法字符、保存成功后返回、失败保留草稿。

## 字符串编辑器 · VMStringEditorViewController

- 单字符串编辑，显示原始容量与编辑字节数量；支持 UTF-8。
- 附近字符串列表、前后加载 1 KB、点击切换字符串、选中项定位。
- 显式起止地址范围编辑，终止地址包含在范围中；范围内容以转义字节编辑，写入长度相等。
- 保存、撤销、重新读取；切换、重读、关闭时询问草稿处理；范围写入展示前后预览。
- 横屏、小高度和键盘避让；文本编辑区拥有键盘收起工具栏。
- 保留 `VMStringMemorySession`：严格地址解析、读取完整性、目标会话校验、字节容量、写入前冲突检测、写后读回校验、撤销记录和上下文大小上限。

## 模块选择器 · VMModuleListViewController

- 异步读取远程模块并按大小排序；模块名称搜索；显示模块名、基址、内存大小。
- 主模块使用星标；自动搜索全部区域；选择结果通过回调返回上一页。
- 重构关注：加载/无匹配状态、搜索保留、稳定的重用样式、国际化和可读元数据。

## 特征码分析器 · VMSignatureSearchViewController

- 显示目标地址；选择 ±8、±16、±32、±64 字节；读取邻近字节。
- 自动掩盖目标值字节；点击字节切换 `??`；智能掩码；恢复原始字节。
- 验证签名，显示扫描中、唯一匹配、多个匹配、零匹配和耗时；点击结果打开统一地址动作。
- 保存备注、签名、作者到工具箱；记录目标应用、模块、偏移；保存后可直接跳转相应工具箱文件。
- 保留全区域扫描行为。原代码具有模块选择方法，但页面没有对应可见入口。
- 重构关注：响应式配置/结果布局、44 pt 字节格和操作、任何字节变化使旧验证结果失效、明确空状态。

## 断点监视器 · VMWatchpointViewController

- 附加/分离调试引擎；显示槽位占用与命中数量；添加写入监视点（4 字节）；移除槽位；清空监视点及命中。
- 槽位/命中列表切换；槽位点击定位最近命中；进程改变时分离并清空。
- 命中记录包含模块、偏移、PC、数值、地址、槽位；点击打开代码检查器。
- 代码检查器显示整段反汇编与 PC；选择指令、输入 Hex、应用补丁；NOP、RET、MOV W0,#0、MOV W0,#1 快捷填值。
- 复制所选 Hex、模块偏移、整段反汇编；保存为 RVA 补丁；打开 ARM Converter；键盘收起。
- 重构关注：状态驱动按钮、清晰空状态、可访问性、检查器适配安全区域、旋转和键盘，保留全部工具。

## 进程审计 · VMProcessAuditViewController

- 通过 bundle ID 定位进程；显示应用、bundle ID、PID/运行状态。
- 静态比较磁盘文件与运行时代码；动态等待进程、建立快照、再次操作比较快照。
- 显示模块/偏移、原始字节和当前字节；复制差异；还原字节；导出文本报告；帮助说明。
- 重构关注：明确扫描/等待/快照/完成状态，自适应信息卡，避免重复扫描，还原后刷新结果。

## 共享地址动作 · VMMemoryActionSheet

- 编辑备注、修改数值/字符串、撤销该地址上次写入、指针分析、特征码分析、监视点。
- 数值/字符串浏览、Hex 浏览、偏移计算、锁定、收藏、复制地址。
- 指针项目支持卡片/滑块显示模式、滑块最小/最大值配置。
- 字符串入口创建绑定进程的编辑会话；任何目标变化终止旧会话写入。
- 重构关注：保持所有分支与跳转；编辑反馈根据写入结果呈现。

## 统一体验准则

分组背景、16 pt 内容边距、连续圆角信息卡；靛蓝主操作与语义状态色；技术数据采用可读等宽字体。内容适配安全区域、键盘与窗口宽度，主要操作目标至少 44 pt。错误、空状态、选中状态同时具有可读文字或图形信息。

## 本轮实现与回归重点

- 浏览器类型切换移到内容卡片，显示基址和跳转；多选增加显式入口、勾选、可访问性状态。数值行提升到 60 pt，异步请求绑定页面 generation 与进程，前后分页保留滚动位置。
- Hex 视图随宽度采用 4/8/16 字节行，显示地址和内容两层信息；支持部分尾行；编辑器显示实时字节长度，严格校验输入，失败保留草稿，支持显式重读；执行区确认后再次校验基线，成功写入读回核对后返回。
- 特征码布局使用持有的响应式约束；调整掩码/范围统一废弃旧验证结果；存储偏移依据当前签名内的位置；扫描、结果读取/操作与保存绑定原始目标进程，工具箱跳转使用稳定标签标识。
- 监视点页面提供明确的附加可用状态；代码检查器采用安全区约束与滚动内容，适配旋转、键盘、44 pt 以上操作目标和 VoiceOver 模态焦点。
- 模块页增加加载/无匹配状态，异步返回保留当前搜索条件；审计页改为自适应信息卡，快照任务在共享串行队列后台执行，原子 epoch 区分页面/目标会话归属；等待进程可取消，还原后更新差异。
- 内存页面统一非模态状态反馈，数值写入失败按真实返回值反馈；失败写入保留原有撤销记录。字符串会话模型保持原样。
- 静态验证：全部 9 个修改的 Objective-C++ 控制器/动作实现通过 iOS Simulator SDK 语法编译；源码 diff 格式检查通过。实际跨进程写入、硬件断点命中和越狱权限仍由设备环境验证。
